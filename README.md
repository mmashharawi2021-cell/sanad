# opencode · OpenRouter starter

مشروع TypeScript صغير يضيف OpenRouter عبر الـ SDK الرسمي `@openrouter/sdk`،
مع طلب واحد يعمل من البداية للنهاية، ومعالجة أخطاء واضحة، وصفحة ويب عربية للتجربة السريعة.

```
src/config.ts      قراءة OPENROUTER_API_KEY واسم الموديل من البيئة
src/openrouter.ts  إنشاء عميل SDK + دالة ask() + تحويل الأخطاء إلى رسائل مفهومة
src/cli.ts         تشغيل الطلب من الطرفية
src/server.ts      خادم HTTP صغير: يقدّم الصفحة + POST /api/chat
public/index.html  الصفحة (RTL) لإرسال الأسئلة ورؤية الرد
```

## المتطلبات

- Node.js 20 أو أحدث (تم الاختبار على Node 26)
- حساب OpenRouter ورصيد بسيط (الموديلات المدفوعة تُخصم من الرصيد)

> على هذا الجهاز صلاحية تشغيل سكربتات PowerShell معطّلة، لذا استخدم `npm.cmd` بدل `npm`
> إن ظهر خطأ `running scripts is disabled`.

## 1) إنشاء المفتاح

أنشئ مفتاحاً من <https://openrouter.ai/keys> ثم مرّره كمتغير بيئة — لا تضعه في الكود أبداً.

**PowerShell (الجلسة الحالية فقط):**

```powershell
$env:OPENROUTER_API_KEY = "sk-or-v1-..."
```

**أو ملف `.env` (دائم، ومستثنى من Git):**

```powershell
Copy-Item .env.example .env
notepad .env
```

ضع فيه:

```ini
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=anthropic/claude-opus-5.5
```

## 2) التثبيت والتشغيل

```powershell
npm.cmd install
```

### أ) من الطرفية — طلب واحد كامل

```powershell
npm.cmd run chat -- "اشرح الفرق بين REST وGraphQL في ثلاث نقاط"
```

بدون سؤال يستخدم البرومت الافتراضي. الناتج يظهر مع اسم الموديل والزمن وعدد التوكنز.

### ب) صفحة الويب

```powershell
npm.cmd run dev
```

ثم افتح <http://localhost:3000> — اكتب السؤال، اختر الموديل بالـ slug، واضغط إرسال
(أو `Ctrl + Enter`). الأخطاء تظهر في الصفحة مع تلميح للإصلاح.

### ج) فحص الأنواع

```powershell
npm.cmd run typecheck
```

## اختيار الموديل

كل موديل له slug، مثل `anthropic/claude-opus-5.5` أو `openai/gpt-6.1-sol`.
القائمة الكاملة: <https://openrouter.ai/models> — أو اطلبها برمجياً من `GET /api/v1/models`.

- الافتراضي في الكود: `anthropic/claude-opus-5.5` (من `src/config.ts`)
- لتغييره مؤقتاً: `$env:OPENROUTER_MODEL = "openai/gpt-6.1-sol"`
- أو من الصفحة نفسها عبر حقل «موديل (slug)»

## المجاني بالكامل

الموديلات المجانية على OpenRouter تنتهي بـ `:free` وتكلفتها صفر. هذا المشروع مضبوط عليها
حالياً، فلا يحتاج أي رصيد.

| الموديل | نقاط القوة | ملاحظة |
| --- | --- | --- |
| `nvidia/nemotron-3-ultra-550b-a55b:free` | أفضل جودة عربية، 550B، سياق ~1M | أبطأ (5–9 ثوانٍ) |
| `particle-ai/particle-1:free` | أسرع رد (~1.5 ثانية) وجودة جيدة | مناسب للتجربة السريعة |
| `google/gemma-4-31b-it:free` | جودة جيدة | قد يرجع `429` مؤقتاً |
| `openrouter/free` | راوتر يختار أي موديل مجاني متاح | الأفضل كاحتياط |

**حدود الاستخدام:** بلا رصيد = 50 طلباً يومياً لكل الموديلات المجانية. إذا اشتريت رصيداً
بقيمة \$10 مرة واحدة، يرتفع الحد إلى 1000 طلب يومياً (ويبقى الاستخدام على الموديلات
المجانية بلا تكلفة).

**التبديل التلقائي:** `OPENROUTER_FALLBACK_MODELS` في `.env` قائمة موديلات بديلة — إن فشل
الأول (حد طلبات، انقطاع، إلخ) يجرّب التالي تلقائياً. الافتراضي هنا:

```ini
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
OPENROUTER_FALLBACK_MODELS=particle-ai/particle-1:free,openrouter/free
```

بعد شحن الرصيد بدّل السطر الأول إلى `anthropic/claude-opus-5.5` للحصول على أفضل جودة.

## معالجة الأخطاء

| الحالة | ما يحدث |
| --- | --- |
| المفتاح غير موجود | رسالة تشرح كيفية إنشائه ووضعه، بدون أي طلب شبكة |
| `401` | «OpenRouter rejected the API key» + رابط إنشاء مفتاح |
| `402` | لا يوجد رصيد + رابط الشحن |
| `400` / `422` | طلب غير صالح (slug خاطئ أو رسالة غير صحيحة) |
| `404` | الموديل غير موجود + رابط قائمة الموديلات |
| `429` | تجاوز حد الطلبات + نصيحة بالانتظار |
| `5xx` | خطأ من OpenRouter أو المزوّد + إعادة المحاولة |
| انقطاع الشبكة | «Could not reach OpenRouter» |
| مهلة | 90 ثانية للـ SDK و100 ثانية للصفحة، مع رسالة `504` |

كما تُرفض الطلبات بالتحقق: برومت فارغ (`400`)، جسم غير JSON (`400`)،
وجسم أكبر من 16 كيلوبايت (`413`).

## ملاحظات

- لا يُسجَّل المفتاح في السجلات ولا يُرسل للمتصفح؛ الطلبات تمر عبر خادمك المحلي فقط.
- `.env` و`node_modules` مستثناة في `.gitignore`. استخدم `.env.example` كقالب.
- المستودع يحتوي حماية مسبقة للـ commit (`.githooks/pre-commit`، مُفعّلة عبر `core.hooksPath`):
  ترفض أي commit يضم ملف `.env` حقيقياً أو نصاً يشبه مفتاح OpenRouter. لتجربتها:
  ضع مفتاحاً وهمياً في ملف وأضفه ثم `git commit` — سيُرفض.
- إن ظهرت العربية مشوّشة في الطرفية: `chcp 65001` قبل التشغيل.
