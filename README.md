# opencode · OpenRouter starter

مشروع TypeScript صغير يضيف OpenRouter عبر الـ SDK الرسمي `@openrouter/sdk`،
مع طلب واحد يعمل من البداية للنهاية، ومعالجة أخطاء واضحة، وبث للردود،
وواجهة عربية بطراز **Neumorphism** (وضعان: داكن وفاتح) تدعم محادثات متعددة
وحفظها محلياً واختيار الموديل من قائمة الموديلات المجانية.

```
src/config.ts      قراءة OPENROUTER_API_KEY واسم الموديل من البيئة
src/openrouter.ts  عميل SDK + ask() + askStream() + تحويل الأخطاء إلى رسائل مفهومة
src/cli.ts         تشغيل الطلب من الطرفية (عادي أو --stream)
src/server.ts      خادم HTTP: الصفحة + POST /api/chat + POST /api/chat/stream (SSE) + GET /api/models
public/index.html  الصفحة (RTL، Neumorphism، محادثات متعددة، اختيار الموديل، بث مباشر)
```

## المتطلبات

- Node.js 20 أو أحدث (تم الاختبار على Node 26)
- لا حاجة لرصيد: الإعداد الافتراضي يستخدم موديلات مجانية

> على هذا الجهاز صلاحية تشغيل سكربتات PowerShell معطّلة، لذا استخدم `npm.cmd` بدل `npm`
> إن ظهر خطأ `running scripts is disabled`.

## 1) إنشاء المفتاح

أنشئ مفتاحاً من <https://openrouter.ai/keys> ثم مرّره كمتغير بيئة — لا تضعه في الكود أبداً.

**PowerShell (الجلسة الحالية فقط):**

```powershell
$env:OPENROUTER_API_KEY = "sk-or-v1-..."
```

**أو ملف `.env` (دائم، ومستثنى من Git):**

```powershell
Copy-Item .env.example .env
notepad .env
```

ضع فيه:

```ini
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
```

## 2) التثبيت والتشغيل

```powershell
npm.cmd install
```

### أ) من الطرفية — طلب واحد كامل

```powershell
npm.cmd run chat -- "اشرح الفرق بين REST وGraphQL في ثلاث نقاط"
```

بدون سؤال يستخدم البرومت الافتراضي. الناتج يظهر مع اسم الموديل والزمن وعدد التوكنز.

لعرض الرد أثناء توليده:

```powershell
npm.cmd run chat -- --stream "اكتب ثلاث نصائح لتحسين التركيز"
```

### ب) صفحة الويب

```powershell
npm.cmd run dev
```

ثم افتح <http://localhost:3000>. الواجهة عربية بالكامل (RTL) بطراز Neumorphism:

- **محادثات متعددة** في الشريط الجانبي: «＋ محادثة جديدة» أو `Ctrl + K`، وحذف أي محادثة بزر ✕.
  كل شيء يُحفظ في `localStorage`، فتبقى المحادثات بعد إعادة تحميل الصفحة.
- **اختيار الموديل** من قائمة منسدلة تُبنى تلقائياً من `GET /api/models` (الموديلات المجانية فقط،
  مع حجم السياق)، والاختيار يُحفظ لكل محادثة.
- **إرسال** بـ `Enter`، وسطر جديد بـ `Shift + Enter`؛ الرد يظهر **كلمة بكلمة** مع زر «إيقاف».
- **لكل رد**: اسم الموديل، الزمن، عدد التوكنز، وأزرار «نسخ» و«إعادة التوليد»، وزر «إعادة المحاولة»
  عند الخطأ. الردود تُعرض كـ Markdown آمن (عناوين، قوائم، أكواد مع زر نسخ، روابط `https` فقط).
- **المظهر**: زر واحد للتبديل بين الداكن والفاتح، ويُحفظ الاختيار.
- **إحصاءات**: عدد طلبات اليوم من أصل 50، ومتوسط زمن الرد، في أسفل الشريط الجانبي.
- على الجوال يتحول الشريط الجانبي إلى قائمة منسدلة مع خلفية معتمة.

### ج) واجهة البث المباشر (SSE)

`:POST /api/chat/stream` يرسل الأحداث التالية:

| الحدث | البيانات |
| --- | --- |
| `delta` | `{ "text": "..." }` مقطع من الرد |
| `done` | `{ "model", "latencyMs", "usage" }` |
| `error` | `{ "error", "hint" }` |

```powershell
curl.exe -N http://localhost:3000/api/chat/stream `
  -H "Content-Type: application/json" `
  -d '{\"prompt\":\"مرحبا\"}'
```

ولمحادثة متعددة الأدوار أرسل `messages` بدل `prompt`:

```powershell
curl.exe -N http://localhost:3000/api/chat/stream `
  -H "Content-Type: application/json" `
  -d '{\"model\":\"openrouter/free\",\"messages\":[{\"role\":\"user\",\"content\":\"اسمي زياد\"},{\"role\":\"assistant\",\"content\":\"أهلاً زياد\"},{\"role\":\"user\",\"content\":\"ما اسمي؟\"}]}'
```

يبقى `POST /api/chat` متاحاً ويعيد الرد كاملاً في استجابة JSON واحدة (ويقبل `messages` أيضاً).
عند إغلاق المتصفح يتوقف الاتصال بـ OpenRouter تلقائياً، وتُرسل نبضات `: keep-alive`
كل 15 ثانية، والمهلة القصوى 120 ثانية.

### د) قائمة الموديلات المجانية

`GET /api/models` يعيد الموديلات التي تكلفتها صفر والقادرة على محادثة نصية
(يستبعد موديلات الصوت/الصور)، مع حجم السياق، ومخزّنة مؤقتاً 10 دقائق:

```json
{
  "default": "nvidia/nemotron-3-ultra-550b-a55b:free",
  "models": [{ "id": "...", "name": "...", "contextLength": 1048576, "maxOutput": 32768, "inputModalities": ["text"] }]
}
```

### هـ) فحص الأنواع

```powershell
npm.cmd run typecheck
```

## اختيار الموديل

كل موديل له slug، مثل `anthropic/claude-opus-5.5` أو `openai/gpt-6.1-sol`.
القائمة الكاملة: <https://openrouter.ai/models> — أو من `GET /api/models` في هذا المشروع.

- الافتراضي: `nvidia/nemotron-3-ultra-550b-a55b:free` (من `src/config.ts` أو `OPENROUTER_MODEL`)
- لتغييره مؤقتاً: `$env:OPENROUTER_MODEL = "openai/gpt-6.1-sol"`
- أو من الصفحة نفسها عبر قائمة الموديل في الأعلى (لكل محادثة اختيار مستقل)

## المجاني بالكامل

الموديلات المجانية على OpenRouter تنتهي بـ `:free` وتكلفتها صفر. هذا المشروع مضبوط عليها
حالياً، فلا يحتاج أي رصيد.

| الموديل | نقاط القوة | ملاحظة |
| --- | --- | --- |
| `nvidia/nemotron-3-ultra-550b-a55b:free` | أفضل جودة عربية، 550B، سياق ~1M | أبطأ (5–9 ثوانٍ) |
| `particle-ai/particle-1:free` | أسرع رد (~1.5 ثانية) وجودة جيدة | مناسب للتجربة السريعة |
| `google/gemma-4-31b-it:free` | جودة جيدة | قد يرجع `429` مؤقتاً |
| `openrouter/free` | راوتر يختار أي موديل مجاني متاح | الأفضل كاحتياط |

**حدود الاستخدام:** بلا رصيد = 50 طلباً يومياً لكل الموديلات المجانية. إذا اشتريت رصيداً
بقيمة \$10 مرة واحدة، يرتفع الحد إلى 1000 طلب يومياً (ويبقى الاستخدام على الموديلات
المجانية بلا تكلفة).

**التبديل التلقائي:** `OPENROUTER_FALLBACK_MODELS` في `.env` قائمة موديلات بديلة — إن فشل
الأول (حد طلبات، انقطاع، إلخ) يجرّب التالي تلقائياً. الافتراضي هنا:

```ini
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
OPENROUTER_FALLBACK_MODELS=particle-ai/particle-1:free,openrouter/free
```

بعد شحن الرصيد بدّل السطر الأول إلى `anthropic/claude-opus-5.5` للحصول على أفضل جودة.

## معالجة الأخطاء

| الحالة | ما يحدث |
| --- | --- |
| المفتاح غير موجود | رسالة تشرح كيفية إنشائه ووضعه، بدون أي طلب شبكة |
| `401` | «OpenRouter rejected the API key» + رابط إنشاء مفتاح |
| `402` | لا يوجد رصيد + رابط الشحن |
| `400` / `422` | طلب غير صالح (slug خاطئ أو رسالة غير صحيحة) |
| `404` | الموديل غير موجود + رابط قائمة الموديلات |
| `429` | تجاوز حد الطلبات + نصيحة بالانتظار |
| `5xx` | خطأ من OpenRouter أو المزوّد + إعادة المحاولة |
| انقطاع الشبكة | «Could not reach OpenRouter» |
| مهلة | 90 ثانية للـ SDK و120 ثانية للبث، مع رسالة `504` |
| خطأ أثناء البث | حدث `error` مع التلميح، ويبقى النص الذي ظهر حتى لحظة الخطأ |

كما تُرفض الطلبات بالتحقق:

| الحالة | الحد |
| --- | --- |
| جسم غير JSON أو برومت/رسائل فارغة | `400` |
| `messages` ليست مصفوفة أو دور غير صالح | `400` |
| أكثر من 40 رسالة في الطلب | `413` |
| رسالة واحدة أطول من 8000 حرف | `413` |
| جسم الطلب أكبر من 128 كيلوبايت | `413` |

> ملاحظة: بعض مزوّدي الموديلات المجانية يجمّعون الرد ثم يرسلونه دفعة واحدة، فيبدو البث
> كأنه غير متدفق. هذا سلوك المزوّد لا الكود؛ مع موديلات أسرع يظهر الفرق واضحاً.

## ملاحظات

- لا يُسجَّل المفتاح في السجلات ولا يُرسل للمتصفح؛ الطلبات تمر عبر خادمك المحلي فقط.
- `.env` و`node_modules` مستثناة في `.gitignore`. استخدم `.env.example` كقالب.
- المستودع يحتوي حماية مسبقة للـ commit (`.githooks/pre-commit`، مُفعّلة عبر `core.hooksPath`):
  ترفض أي commit يضم ملف `.env` حقيقياً أو نصاً يشبه مفتاح OpenRouter. لتجربتها:
  ضع مفتاحاً وهمياً في ملف وأضفه ثم `git commit` — سيُرفض.
- إن ظهرت العربية مشوّشة في الطرفية: `chcp 65001` قبل التشغيل.
