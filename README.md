# 🛸 سند (SANAD) — المساعد الشخصي الذكي والأصيل لنظام Windows 11

> **سند (SANAD):** رفيق ذكي، أمين، فائق السرعة، مصمم ليعمل كـ Copilot محلي مباشر على لابتوبك بنظام Windows 11 لمساعدة المطورين والمستخدمين اليوميين في إدارة المهام، البرمجة، الطرفيات، وتحسين أداء النظام.

---

## ✨ أبرز القدرات والمميزات (Core Capabilities)

### 1. 🛸 الجزيرة التفاعلية (Dynamic Island)
- تعرض حالة سند أثناء الاستماع والتحدث والتفكير وتنفيذ الأوامر، مع ملخص الرد الأخير.
- تتيح إدخال أمر سريعاً، والتحكم بالصوت، واستخدام إجراءات لوحة المفاتيح والفأرة من اللوحة الموسّعة.
- وضع العرض المصغّر يخفي مساحة العمل ويُبقي الجزيرة الحديثة ظاهرة، مع زر للعودة إلى الواجهة الكاملة.

### 2. 🎙️ الحوار الصوتي المستمر وكلمة التنبيه (Full-Duplex Voice & Wake Word)
- **كلمة التنبيه الذاتية:** نداء *"يا سند"* أو *"سند"* يوقظ المساعد فوراً حتى لو كانت النافذة في الخلفية.
- **الحوار الصوتي المتواصل (Full-Duplex):** تحدث واستمع للردود الفصيحة بشكل طبيعي متصل دون الحاجة لضغط زر المايك بعد كل رد.
- **المقاطعة اللحظية (Barge-in):** التحدث أثناء كلام سند يوقفه فوراً ليستمع لأمرك الجديد بانسيابية.
- الاختصار العالمي: `Ctrl + Shift + V`.

### 3. 🚀 المطور البرمجي الذاتي ومعاينة المشاريع الحية (Autonomous Builder & Live Preview)
- بناء وتوليد مشاريع وتطبيقات ويب كاملة من الصفر بنقرة زر أو أمر صوتي (`web-dashboard`، `task-manager`، `python-gui`).
- نافذة معاينة تفاعلية حية (`#previewModalBackdrop`) مدمجة داخل سند لعرض وتجربة التطبيق مباشرة.
- مفتاح تبديل الشاشات: شاشة حاسوب (`100%`) وشاشة جوال متجاوبة (`375px`).
- فتح المشروع فوراً في **Visual Studio Code** بضغطة واحدة.

### 4. 📊 المحلل الذكي ومستكشف أداء النظام ومساعد القرص (Disk & Performance HUD)
- **فاحص الأقراص:** قراءة سعات الأقراص والبارتشنز (`C:` و `D:`) ونسب الاستهلاك عبر WMI CIM.
- **تحرير الذاكرة الفوري (RAM Boost):** تفريغ مساحات العمل الخاملة للبرامج عبر استدعاءات `psapi.dll`، يحرر من 500 إلى 1500 ميجابايت من الرام في ثوانٍ معدودة.
- **فاحص أكبر الملفات (Large Files Inspector):** مسح ذكي لاكتشاف أضخم الملفات والفيديوهات والمثبتات مع زر `📂 إظهار` لفتح موقع الملف في مستكشف الويندوز.
- **التنظيف الآمن:** تفريغ ملفات الكاش والملفات المؤقتة بأمان تام.

### 5. 💻 الطرفية الشاملة وتشخيص الأخطاء (Universal Multi-Terminal)
- دعم 5 بيئات تشغيلية كاملة: **PowerShell** و **Command Prompt (CMD)** و **Python** و **Node.js** و **Git**.
- محرك تشخيص ذاتي للأخطاء: يقترح الأوامر التصحيحية فوراً (مثل `pip install` عند نقص موديول بايثون).

### 6. 🧹 أتمتة سطح المكتب ومجلد التنزيلات (Desktop Automation)
- فرز وترتيب الملفات المبعثرة تلقائياً في مجلدات مصنفة دون حذف أي ملف.
- استثناء ملفات الاختصارات وملفات النظام الحساسة.
- بيئات عمل سريعة بنقرة زر (بيئة البرمجة، بيئة الـ GIS، وتنظيف الشاشة).

### 7. 🧠 العقل المزدوج (Dual Brain: Local Ollama + Cloud OpenRouter)
- تشغيل أوفلاين 100% وبخصوصية تامة عبر النماذج المحلية في خادم Ollama على جهازك (`http://127.0.0.1:11434`).
- دعم الموديلات السحابية المجانية وفائقة الذكاء عبر OpenRouter مع بث حي سريع للردود (SSE).

## 🚀 التثبيت والتشغيل السريع (Quick Start)

> ⚠️ **ملاحظة لنظام Windows:** استخدم `npm.cmd` لتفادي قيود تشغيل سكربتات PowerShell على جهازك.

### 1. تثبيت الحزم:
```powershell
npm.cmd install
```

### 2. ضبط مفتاح OpenRouter (اختياري للوضع السحابي):
انسخ `.env.example` إلى `.env` وضع مفتاحك:
```ini
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
```

### 3. تشغيل النظام:
```powershell
# خادم التطوير مع التحديث التلقائي
npm.cmd run dev
```
ثم افتح متصفحك على: <http://localhost:3000>

### أو عبر الاختصارات السريعة:
- تشغيل بنقرة واحدة: `run.bat`
- تشغيل مخفي في الخلفية مع الكبسولة العائمة: `JARVIS.vbs`

## ⌨️ جدول الاختصارات العالمية (Keyboard Shortcuts)

| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Alt + S` | إظهار / إخفاء نافذة «سند» والكبسولة العائمة فوراً من أي مكان في الويندوز |
| `Ctrl + Shift + V` | تفعيل / إيقاف وضع الحوار الصوتي المباشر (Full-Duplex Live Voice) |
| *"يا سند"* أو *"سند"* | كلمة التنبيه الصوتية (Wake Word) لإيقاظ سند وبدء الاستماع |
